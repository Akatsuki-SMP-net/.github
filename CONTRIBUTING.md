# Contributing to AKATSUKI SMP

Thanks for helping improve our projects.

## Before making changes

1. Check the relevant repository's README and existing Issues.
2. For significant changes, open an Issue first so the team can discuss the approach.
3. Keep changes focused and explain why they are needed.

## Pull requests

- Describe what changed and why.
- Include steps to test the change.
- Mention any limitations or follow-up work.
- Do not include passwords, access tokens, private player information, or server secrets.

Project-specific instructions in an individual repository take precedence over this general guide.
